# Scroll Car Animation

A React and Vite recreation of the pinned, scroll-controlled car scene, built with HTML, CSS, JavaScript, Tailwind CSS, GSAP, and ScrollTrigger. Tailwind utilities handle the base layout; the scene-specific visual styling lives in `src/index.css`. The car image is the McLaren asset used by the reference page and can be replaced at `public/car.png`.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```
